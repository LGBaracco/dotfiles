# Writing an atlas `config.py`

Paths relative to `$ATLAS_SRC/atlas/` (atlas `v0.3.0-6-gc64050cf`); `config.py:N` = `configuration/config.py`. If a line moved, `rg -n "class <Name>" $ATLAS_SRC/atlas/configuration`.
Starter: `../templates/config_minimal.py`. Full examples: `$ATLAS_SRC/examples/config/config_cytonet_{pretrain,finetune}.py`, `config_flow_matching[_feature_regularizer].py` (summaries in §10).
Models/losses/SSL: `models-losses.md`. Data sources and sample files: `data-sources.md`.

Shorthand: none, every option name is written out in full; a misspelled kwarg is silently ignored.
Sections: 1 skeleton · 2 constants & globals · 3 TrainParams · 4 modes · 5 optimisation · 6 data params · 7 samplers · 8 augmentation · 9 finetune/freeze/checkpoints · 10 examples · 11 pitfalls · 12 `.atlas.json`

## 1. Skeleton
- Loaded by `experiments/experiments.py:19 load_config` (module import; rank 0 reads + broadcasts when distributed). Every rank (GPU masters **and** CPU slaves) executes it.
- `make_training_parameters(**kw) -> config.TrainParams` — called **with no kwargs** by `dl train|predict|predict-points|evaluate` and `exp` tools (so it also runs at prediction time: don't assert training-only files exist unless needed).
- `make_network(**kw) -> nn.Module` — kwargs: `input_shape` (list, one shape per input, e.g. `[(None,C,H,W)]`), `input_spacing`, `num_classes` (segmentation, evidential, domain-adversarial and at prediction time; predict-points passes 42 if unset), `condition_data_source` (flow matching). GAN modes return `(G, D)`.
- Optional: `make_feature_model(**kw)` (feature regulariser), `make_trainer(...)` (`mode="custom"`), `weight_init_func`, `post_weight_init_func`, `train_model_func`, `eval_model_func`.
- Module level: constants only; put imports inside functions (cheap on every rank).
- Batch size is **per GPU master**: `n = parallel.NUM_MASTERS if parallel.IS_DISTRIBUTED else 1; assert TOTAL % n == 0; batch_size = TOTAL // n`. `parallel` globals are valid inside `make_training_parameters` during `dl train` (MPI set up first, `cli/dl.py:291` before `:387`); elsewhere `NUM_MASTERS=1`, `IS_DISTRIBUTED=False`.

## 2. Constants and globals
- Splits `config.TRAIN_SPLIT="train"` (required), `TEST_SPLIT="test"` (only with `test_interval`), `VAL_SPLIT="val"` (only `dl predict`/`segment`/`evaluate`). `iterator_params={config.TRAIN_SPLIT: IteratorParams(...), ...}`.
- `backend="torch"` (only backend; not "pytorch").
- Channels (`data/image_provider.py:20-30`, re-exported in config): `CHANNEL_HISTOLOGY="histology"` (=`CHANNEL_GRAY`), PLI `CHANNEL_TRANSMITTANCE|DIRECTION|RETARDATION`, `CHANNEL_BG_COR_WM_SEGMENTATION`, `CHANNEL_ANNOTATIONS`, `CHANNEL_TISSUE`, `CHANNEL_PMAP="pmap"`, `CHANNEL_RAS="ras"`. Path-like `"pmap/hOc1"` = channel + sub-dataset; sliced `"name[0]"`, `"name[0:2]"`; new channels = new key in `FILE_PARAMETERS`.
- `parallel` (`experiments/parallel.py:36-81`): `NUM_MASTERS`, `IS_DISTRIBUTED`, `IS_MASTER`, `IS_SLAVE`, `IS_COORDINATOR`, `WORLD_RANK/SIZE`, `LOCAL_RANK/SIZE`, `LOCAL_GPUS`, `NODE_COUNT`, `TOTAL_GPUS`, `NUM_SLAVES`.
- `Params` base (`config.py:103`): unknown kwargs are stored silently, missing attributes read as `None`, unset `RequiredValue` raises. `OutputFormat(size, spacing)` (`:83`). Params are JSON-serialised (`ConfigJSONEncoder` `:184`) into diagnostics and every checkpoint → no `functools.partial`/third-party objects in params.

## 3. `TrainParams` (`config.py:247`)

- Loss: `loss_type="categorical_cross_entropy"`, `loss_kwargs={}`, `class_weights` (1D or NxN rows=true), `use_loss_mask` + `loss_mask_value` (or callable) + `loss_mask_data_source="mask"`, `enable_pmap_aware_loss_weights` / `enable_section_aware_loss_weights` (positive-unlabelled helpers in `torch/positive_unlabeled_training.py`, need bg/cor/wm labels).

- I/O: `input_output_mapping=ds.InputOutputMapping(input=..., output=...)` (must be this class except SSL dict), `prediction_input_output_mapping_key`, `prediction_cropping_size={ds: size}`, `prediction_filename_pattern`, `segmentation_label_data_source`.
- Metrics: `metrics=["accuracy","precision","recall","f1","iou","confusion_matrix"]`, `display_metrics=["accuracy","f1"]`; tolerance via kwarg `metric_tolerance`, threshold via kwarg `segmentation_accuracy` (π/4).
- Early stopping: `early_stopping_quantity` (= `loss_type` key or metric name), `early_stopping_mode="min"`, `early_stopping_patience=None` (off), `early_stopping_min_delta`, `early_stopping_lr_control`, `early_stopping_levels`.
- Visualisation (intervals): `visualize_gradients|weights|output_histogram|input_images|output_images|test_embeddings`, kwarg `visualized_embeddings`, `visualize_model=True`, `show_example_interval` + `show_examples_list=[{brain, section, center, spacing}]`, `show_batch_example_interval`, `save_batches_interval`.
- Logging: `log_memory_usage_interval`, `log_peak_memory`, `log_timings[_interval]`, `average_metrics_interval`, `add_batches_to_diagnostics`.
- Distributed: `sync_batch_norm_statistics` (only when distributed; important for contrastive), `use_safe_norm`, `distributed_training_framework="torch"|"horovod"`, `ddp_find_unused_parameters`, `ddp_kwargs`, `torch_distributed_backend="nccl"|"gloo"`, `torch_distributed_init="tcp"|"file"`, `torch_tcp_init_port=23456`, `torch_deterministic`, `torch_cudnn_benchmark=True`, `torch_pinned_memory_transfer`, `batch_stager_num_threads`.
- Profiling: kwarg `torch_profiling`, `torch_profiling_{activities,record_shapes,memory,chrome_trace,flame_graph,tensorboard,schedule_params,coordinator_only}`.
- Hard-negative mining: `hard_negative_mining_params=HardNegativeMiningParams(data_source_name, adjust_probability_interval=50, ...)` (`:1041`; switches to centralised batch iterator).
- Undeclared but read (pass as kwargs): `regression_log_before_loss`, `annealing_coef` (evidential), `domain_adversarial_factor_function(iteration, trainer=)`, `domain_adversarial_optimizer_params`, `visualize_sequence` (cpc), `use_wandb`/`wandb_*` (dist_pretrain).
- Dead (no effect): `torch_compile` (compiles a local var, `torch/training/trainer.py:813`), `enable_gradient_checkpointing`, `gradient_checkpoint_selector`, `visualize_kernels|bn_statistics|activations_histogram|input_statistics`, `distributed_snapshot`, `evaluate_metrics_per_label`, `OptimizerParams.learning_rate_multiplier_per_layer`. For memory saving use model options (`ViTConfig(gradient_checkpointing=True)`, `memory_efficient=True` on ResNet/ConvNeXt, `torch/models/checkpoint.py:95`).

## 5. Optimisation
- `OptimizerParams` (`config.py:880`): `optimizer="sgd"|"adagrad"|"rmsprop"|"adadelta"|"adam"|"adamw"`, `learning_rate_params` (Req), `param_group_selectors=[callable(model)→params]`, `weight_decay` (scalar or per-group list), `sgd_momentum=.9`, `sgd_nesterov=True`, `adam_beta1/2`, `rmsprop_rho`, `adadelta_rho`, `distributed_learning_rate_scaling=True` (lr × NUM_MASTERS; examples set False and scale by total batch), `lars_enable`, `lars_trust=.02`, `lars_clip=True`, `amp_params`.
- `LearningRateParams` (`:806`): `learning_rate` (Req), `start_iteration=0`, `lr_policy` ∈ `None/"constant"`, `"warmup"` (`warmup_iterations`), `"piecewise"` (`piecewise_steps`, `piecewise_values`), `"linear"` (`linear_slope`), `"lambda"` (`lambda_fn(epoch)`), `"cosine"` (`cosine_max_iterations` Req = phase length with `use_relative_epoch=True`, `cosine_min_lr`). `exponential|inverse_time|natural_exp|step` raise. A list of LRParams = phases (largest `start_iteration` ≤ it wins). `"warmup"` ramps lr → lr×distributed multiplier, i.e. constant when scaling is off.
- `LearningRateParamsPerParamGroup(*lists)` (`:848`): one list per param group = `len(param_group_selectors)`. Standard pattern: selectors `[WeightDecaySelector(), WeightDecaySelector(inverse=True)]`, `weight_decay=[wd, 0.0]`.
- `AmpParams` (`:943`): `enabled=None` (None/True = on), `dtype="float16"|"bfloat16"`, `init_scale`, `growth_*`. `amp_params=None` = off. `AmpParams()` = fp16 autocast + GradScaler.
- Selectors (`torch/optimizers/optimizers.py`): `WeightDecaySelector(inverse, regularize_batch_norm_weight, include_type_list, exclude_type_list)` (`:235`, raises on unknown module types holding direct params — e.g. custom `nn.Parameter` tokens, PReLU → use include/exclude lists), `CombinedParameterSelector(selectors, mode="or"|"and")` (`:364`), `ParameterSelector` (`:226`).
- GAN modes: `optimizer_params={"generator": OptimizerParams, "discriminator": OptimizerParams}`.

## 8. Augmentation — `TransformationParams` (`config.py:1414`)
Set on `ImageProviderParams(transformation_parameters=...)`; per-channel gating via `FileParams` flags; sources share random params by `affine_transform_group`/`intensity_transform_group`.
- Affine: `random_mirroring`, `random_rotation` + `random_rotation_range=(-pi/8, pi/8)`, `random_discrete_rotation` + `random_discrete_rotation_range=(0,1,2,3)` (× 90°, ~10× faster than free rotation), `random_shearing` + `random_shearing_range`, `random_translation` + `random_translation_range` (radius or (x,y)) + `random_translation_spacing`, `random_scaling` + `random_scaling_range`, `random_downup_scaling_probability`, `random_downup_scaling_factor`.
- Intensity: `apply_gwn` + `gwn_std=.05`, `brightness_augmentation` + `brightness_augmentation_range=(-.1,.1)`, `contrast_augmentation` + `contrast_augmentation_range=(.9,1.1)`, `gamma_contrast_augmentation` + `gamma_contrast_augmentation_unbiased` (range inside (-.5,.5)) + `gamma_contrast_augmentation_range` + `gamma_contrast_augmentation_probability` + `gamma_contrast_augmentation_parameter_selector`, `random_inversion` + `random_inversion_probability=.5`, `random_gaussian_blur_sharpening` + `random_gaussian_blur_sharpening_probability=(p_none, p_blur, p_sharpen)` + blur std range (kwarg `random_gaussian_blur_std`; the examples pass `random_gaussian_blur_std_range`) + `random_sharpening_std_range` + `random_sharpening_blending_range` (+ `random_gaussian_blur_truncate`, `random_sharpening_truncate`).
- Other: `enable_masking` + `mask_vertices_pattern` + `mask_vertices_spacing`, `enable_histogram_matching` + `histogram_matching_histograms=[(name,(values,counts))]` + `histogram_matching_probabilities` + `histogram_matching_postprocessing_callable`, `enable_zstack_simulation` + `zstack_simulation_bar_width` + `zstack_simulation_probability=.25` + `zstack_simulation_mode="copy"|"psf"` + `zstack_simulation_psf` + `zstack_simulation_psf_center_width` + `zstack_simulation_affine_order="before"|"after"|"random"`, `enable_pre_registration` + `pre_registration_base_slice` XOR `normalize_orientation`, PLI `complex_random_{rotation,direction_offset,direction_flip,scale_thickness,scale_attenuation,gaussian_blur}` (+ `_range` each).
- Order applied (`data/image_provider.py:2424`): hist-match → orientation → gamma → contrast → brightness → noise → blur → sharpen → invert → z-stack → affine → down-up → cross-channel → masking.
- Global off switch: `atlas.data.image_provider.ENABLE_TRANSFORMATION = False`.

## 9. Finetune, freeze, checkpoints
- Init priority (`torch/training/trainer.py:691`): **resume from the run's latest `training_state`** > `NetworkParams.finetune` > `weight_init_func`; then `post_weight_init_func` always runs.
- `NetworkParams` (`config.py:969`): `make_network` (Req), `finetune=<path>` (missing path skipped silently; shape mismatch logged and falls through), `finetune_file_key="model"`, `finetune_mapping={model_key: weights_key}` (required for .hdf5), `weight_init_func(model, trainer, device)`, `post_weight_init_func(model, trainer=None, device=None)`, `train_model_func(model, trainer)` (replaces `model.train()`), `eval_model_func`.
- Freezing: do it in `post_weight_init_func` or `train_model_func` — freezing in `weight_init_func` is lost on resume. Helpers `torch/models/parameters.py`: `freeze_parameters` (`:6`), `lock_normalization_statistics` (`:17`), `finetune` (`:44`, both). Also exclude frozen params in `param_group_selectors` (optimizer is built before weights load).
- Load weights manually: `torch/models/io.py:82 load_weights(model, weights, mapping=None, return_missing, device, key)`.
- Checkpoint `models/training_state_NNNN.pt` = `{iteration, distributed, distributed_training_framework, <model keys>, optimizer, scheduler, scaler, config}` (DDP `module.` stripped; `config` = JSON of TrainParams). Model keys: default `model`; byol `model,target_model`; cyclegan `G_A,G_B,D_A,D_B`; stargan `G,D`; diffusion/flow `model,ema[,feature_regularizer]`; ssl `model` (+`teacher_model` / `target_backbone`). Contrastive with `learnable_temperature` stores a wrapper (keys prefixed `model.` + `loss.log_inverse_temperature`); cpc stores `loss.*` inside `model`.

## 11. Pitfalls
1. Typos/misplaced kwargs are silently ignored; missing fields read `None` (e.g. examples pass `image_provider_seed` to the wrong class).
2. `FILE_PARAMETERS` is one class-level dict shared by every provider/split and resolved from `.atlas.json`/`ATLAS_*` at import → set env before import; `copy.deepcopy` + `file_parameters=` for per-split differences.
3. The config runs on slaves too (`CUDA_VISIBLE_DEVICES=""`): anything GPU-dependent diverges (flow example's batch-size probe).
4. `batch_size` is per GPU; `distributed_learning_rate_scaling=True` multiplies lr by NUM_MASTERS.
5. `file_sampler_samples_key` default `"samples"`; HDF5 files use `"boxes"`.
6. Label/attribute/filter sources can't be network inputs (only Image, Stack, TransformationParam, Probability).
7. Segmentation ignores `loss_kwargs`; regression/LSA accept only `reduction`; don't put `temperature` in ContrastiveLoss `loss_kwargs`; `setup_loss_operation("contrastive")` → NameError (use contrastive mode).
8. `class_weights`/pmap-/section-aware weights need 4D predictions (not patch classification, not with loss masks).
9. `early_stopping_quantity` must match `loss_type` or a metric name.
10. `ViTBody(return_dict=True)` output isn't understood by the SSL parser → `pool="tokens"` or wrap to return `{"pooled","tokens"}`.
11. `ImageDataSource(num_channels=)` must be > `len(channels)`.
12. Check a config without GPUs: `atlas dl train <exp> --dry` / `--fake-data`, or dump batches with `atlas data batch generate <run>/config.py out/ train --batches 2`.

## 12. `.atlas.json` / `ATLAS_*` (`configuration/_constants.py`)
Search order: `$ATLAS_CONFIG_FILE` → `./.atlas.json` → `~/.atlas.json` (else warning, all paths None). `ATLAS_<KEY>` env wins (not `~`-expanded); JSON values get `~`/`$VAR` expansion.
Keys: `experiments_dir`; `{histology,original,transmittance,direction,retardation,probability_map,ras,annotation,bg_cor_wm_segmentation,tissue}_{dir,file,prefix}`; `transformation_{dir,file}`; `orientation_{dir,file}`; `test_set_dir`; `network_dir`; `cache_dir`; `finalize_mpi`; `extra_auxiliary_labels`. `build_path(p, brain, section)` = `p.format(brain=, slice=)`.
Only needed when configs rely on default `FILE_PARAMETERS` paths or for constants-driven tools (`exp test create`, `exp vis`, `img ann2hdf5`). Configs that set their own paths don't need it. Container copy: `atlas-exec cp /atlas/.atlas.json ~/.atlas.json` (galaxy README's `if` around this is inverted).
